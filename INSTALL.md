## Automatic updates

`.github/workflows/readme-studio.yml` redraws the cards every day from fresh GitHub data and commits them when something changed. README.md is never touched, so your own edits to it stay.

- To run it straight away, open the repository's **Actions** tab, choose **Update README cards** and click **Run workflow**.
- If a card's data can't be loaded, that card keeps its last version. The run fails only if no card could be redrawn.
- Public data works with no setup. To include private contributions, add a repository secret named `README_STUDIO_TOKEN` holding a personal access token.
- GitHub pauses scheduled workflows in public repositories after 60 days without activity. If that happens, re-enable it from the Actions tab.
- To change the design, edit it in README Studio and export again.
